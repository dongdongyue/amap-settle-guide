# 租金参考表（静态兜底）

当 WebFetch 抓取贝壳租房页面失败时，用此表作为区域参考租金。

## 使用方式

1. 按 **城市 + 区域名** 匹配，取区间**中位数**作为参考租金。
2. **优先匹配更具体的条目**（如「望京东」优先于「望京」）。
3. 支持**部分匹配**：区域名包含表中关键词即可命中（如「望京西园」→ 望京西）。
4. 未匹配到的区域：用同城市「其他区域」的值，或标注「暂无参考数据」。
5. **实习生预算**：优先看「合租/单间」列（约为同区一居整租的 50%–65%）。
6. 文末 **实习热门区域速查** 可按公司/地铁快速定位条目。

## 更新说明

- 数据来源：综合贝壳、链家、自如 2025-2026 年公开挂牌价
- 区间含义：低值为老旧小区/合租，高值为品质小区/整租
- **合租/单间**：同区域合租单间或隔断间，约为整租一居的 50%–65%，实习生优先参考
- 精度说明：静态数据误差约 ±30%，适合区域间相对比较，不适合精确预算
- 建议每半年更新一次，或优先使用 WebFetch 抓取实时数据
